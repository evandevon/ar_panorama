3 How to make and lock an API key

It's free and takes about five minutes. You only do it once. Use a Google account you look after (a personal one is fine).

  1. Go to console.cloud.google.com and sign in. Make a new project (top bar → project list → New project), and call it something like “360 tours”. Use this project only for the tours.
  2. Turn on the Drive API: search the top bar for Google Drive API, open it and press Enable.
  3. Make the key: APIs & Services → Credentials → Create credentials → API key. Copy it.
  4. Lock it to your website (important): open the key, and under Application restrictions choose Websites. Add your site's address with /* on the end, for example https://yourname.github.io/*. Then under API restrictions choose Restrict key and tick only Google Drive API. Save.
  5. Don't add a billing account (credit card) to this project. The Drive API is free without one.
  6. Changes can take a few minutes to start working. Then paste the key above and run the test.
Can other people use or copy the key?

Anyone who looks at your website's code can see the key; every key used by a web page can be seen like this. Locking it protects you: Google then only accepts it from pages on your website, and only for reading files on Drive that are already shared with “Anyone with the link”. It can't open your own private files, change anything, or cost you money (as long as there's no billing account).

Someone determined could still copy it into their own program and pretend to be your website. The worst they could do is use up the key's daily allowance, so Drive videos in your tours stop loading until the next day. If that ever happens, make a new key, lock it the same way, and delete the old one.
